# Clientology Toolkit

Cursor plugin with two skills:

| Skill | What it does |
| --- | --- |
| **Ďáblův advokát** (`dabluv-advokat`) | Nemilosrdně kritická, konstruktivní zpětná vazba |
| **Image Prompt Enhancer** (`image-prompt-enhancer`) | Přepíše hrubý nápad na detailní EN image prompt ve zvoleném stylu |

Install via the marketplace repo: [jakubSt28/clientology-toolkit-marketplace](https://github.com/jakubSt28/clientology-toolkit-marketplace).
