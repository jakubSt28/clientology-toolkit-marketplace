# Clientology Toolkit

Cursor plugin se šesti skilly:

| Skill | Co dělá |
| --- | --- |
| **Ďáblův advokát** (`dabluv-advokat`) | Nemilosrdně kritická, konstruktivní zpětná vazba |
| **Image Prompt Enhancer** (`image-prompt-enhancer`) | Přepíše hrubý nápad na detailní EN image prompt ve zvoleném stylu |
| **Design audit** (`design-audit`) | Design, UX a přístupnost — hierarchie, kontrasty, CTA, alt texty, focus stavy |
| **Security basics check** (`security-basics-check`) | Uniklé klíče, `.env`, otevřené endpointy, validace vstupů, závislosti |
| **Responsive check** (`responsive-check`) | Co se rozbije na mobilu — přetékání, klikací plochy, navigace, formuláře |
| **SEO + GEO audit** (`seo-geo-audit`) | Metadata, sitemap, structured data + připravenost pro AI vyhledávače |

Install via the marketplace repo: [jakubSt28/clientology-toolkit-marketplace](https://github.com/jakubSt28/clientology-toolkit-marketplace).
